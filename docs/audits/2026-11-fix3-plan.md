## B. Research consulted

- Gemini API keys belong in an `x-goog-api-key` **header**; Google's own REST examples use it —
  <https://ai.google.dev/gemini-api/docs/generate-content/api-key>
- `new URL(import.meta.url).pathname` returns the **percent-encoded** URL path; Node's docs call that
  result incorrect for filesystem use and point at `fileURLToPath` —
  <https://nodejs.org/api/url.html#urlfileurltopathurl-options>
- GSAP is free under the Standard "No Charge" licence and ships on npm, so self-hosting it from
  `node_modules` rather than a CDN needs no licence change —
  <https://gsap.com/community/standard-license/> · <https://unpkg.com/gsap@3.13.0/README.md>
- Meta Graph API accepting `Authorization: Bearer` is **community-sourced only** here
  (<https://stackoverflow.com/a/29900228>); Meta's own docs could not be opened from this session.
  That uncertainty is why fix 6 below ships behind a default-off flag instead of changing the live
  publish path.

## C. Approaches considered

1. **Breadth-first** — take each remaining finding on its own, smallest possible diff per finding.
   Cheap and easy to review, but findings 5, 6, 9 and 12 would each get their own ad-hoc patch at the
   call site, which is how the file got into this state.
2. **Depth-first on the biggest residual risk** — media hosting (finding 6: BPA media published
   through padelrevive.com using another brand's WordPress credentials). Highest value, but choosing
   the replacement host is exactly the owner decision this round is barred from making.
3. **Harden the seam, then fix through it** — findings 5, 6, 9 and 12 share one root cause: every
   external resource (a CDN script, a Mac path, another project's `.env`, an API token, a published
   tagline) is written inline at the point of use, so none of them can be redirected, tested or
   audited. Introduce one small resolver module for those, route the call sites through it, and the
   four findings become configuration instead of code. Unrelated spend-guard findings stay individual.

**Chosen: 3, with 1 for the research/spend-guard items.** Reason: it fixes four findings with one
testable mechanism, it makes the remaining owner decisions (where media is hosted, what the tagline
says, whether Meta takes a bearer header) one-line config changes rather than new code, and a test
asserting "no remote URL and no absolute `/Users/` path survives in the render or the call sites"
stops the class of bug recurring. Cost: one new module and a wider diff than option 1.
